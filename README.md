# My Professional Portfolio

This repository contains my professional portfolio website created for
SWE 380 / CSC 580 Assignment 1.

The project is based on the vCard Personal Portfolio template and is being
customized with my professional background, skills, experience, and projects.

## Project Purpose

The purpose of this website is to present my professional information in a
clear and accessible online portfolio.

## Technologies

- HTML
- CSS
- JavaScript
- Git and GitHub
- GitHub Pages
